本地发布产物位于：

```text
dist/
```

主要文件：

- `MoneyToday.app`：可直接运行的 macOS App。
- `MoneyToday-v1.0.0.zip`：推荐分发包，解压后运行 App。
- `MoneyToday-v1.0.0.pkg`：安装器版本。

## 1.0 核心功能

- 原生 macOS 菜单栏工具。
- 菜单栏实心钱袋图标。
- 点击菜单栏图标打开 popover。
- 首次启动显示设置页。
- 支持填写年薪。
- 支持选择货币。
- 支持设置工作开始和结束时间。
- 默认工作时间为 09:00 到 19:00。
- 自动根据工作日、工作时间和年薪计算今日已赚金额。
- 每 100ms 刷新金额。
- 金额显示 4 位小数。
- 绿色直线进度条显示今日工作进度。
- 支持中国节假日和调休数据。
- 节假日同步放在设置页手动触发。
- 支持本地节假日缓存。
- 支持测试模式，方便周末验收。
- 支持开机启动开关。
- 设置页开关使用绿色开启态和灰色关闭态。
- 主界面展示“已经赚到了什么”的奖励文案。
- 奖励文案配有像素风物品图。
- 主界面和设置界面均为中文简体。
- App 图标使用黄色底和钱袋图形。

## 设计变化

1.0 过程中完成了多轮设计调整：

- 从抽象钱流图标调整为更直观的钱袋图标。
- 从同时展示圆环和直线进度，调整为只保留绿色直线进度条。
- 从主界面展示同步信息，调整为设置页手动同步。
- 从固定副标题文案，调整为更丰富、多元的鼓励文案。
- 从粗颗粒像素图，调整为更精细的像素风物品图。
- 从常驻设置表单，调整为首次设置和齿轮入口。

## 已知限制

- 1.0 未做正式开发者签名。
- 1.0 未做 Apple 公证。
- macOS 首次打开可能提示“未识别开发者”，用户需要右键打开并确认。
- 节假日数据依赖外部 API，可离线使用缓存，但无缓存时会降级为周一到周五。
- 奖励物价锚点为内置近似表，不代表实时市场价格。
- 其他货币暂时只是粗略换算到人民币语境选择奖励文案。
