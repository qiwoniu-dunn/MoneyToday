# MoneyToday 1.2.0 发布记录

## 版本目标

1.2.0 聚焦 1.1 试用后的三个问题：UI 与设计稿还原度不足、奖励文案过于像价格换算、芝麻和商品图缺少互动关系。

本版本不新增商品候选，不新增商品图品类，继续复用 1.1 的 300 个候选和 47 张清晰商品图。

## 主要变化

- 仪表页改为更贴近设计稿的深色玻璃风格，强化金色描边、奶油色文字、绿色状态和大号数字仪表。
- 设置页改为设计稿式列表结构，减少系统表单感。
- 奖励文案改为“当前收入进度对应的单个生活想象锚点”，不展示商品价格，不做多个低价物品折算。
- 奖励区改为 10 条芝麻专用连续循环动画：每次打开窗口随机选择一种姿态，本次打开期间只播放这一条 16 帧、约 2.4 秒的循环，不再在多个姿态之间渐隐切换。
- 奖励商品图批量转为透明底 PNG，移除白色方框背景。
- 奖励区在商品图下方增加完整商品名，避免用户只看到氛围文案却不知道对应哪个物品。
- 主金额右对齐显示，日视图保留三位小数；日/周/月/年视图统一 100ms 刷新，让小数位保持持续跳动。
- 设置页取消主设置表单内部滚动，B 面弹窗高度自动升高，A/B 面切换时允许面板高度变化。
- 增加 snapshot 环境变量，方便固定金额、日期和页面进行截图验收。

## 验证

- `swift build --disable-sandbox`
- `swift run --disable-sandbox MoneyTodayChecks`
- `./scripts/package_app.sh`

自检覆盖：

- 奖励候选仍为 300 个。
- 47 张 `reward-*.png` 商品图资源存在且可读。
- 奖励文案不包含价格换算和任务感禁词。
- 10 组芝麻奖励动画、每组 16 帧 PNG 存在且可读。
- 47 张商品图资源存在透明通道。

## 已知限制

- 1.2.0 仍未做正式开发者签名和公证。
- UI 以设计稿结构和气质为目标，但仍保留 macOS 菜单栏弹窗的毛玻璃特性。
- 芝麻奖励区动效已经改成随机单姿态循环；后续如果要进一步增强，可以继续按商品大类做更强绑定的交互动作。
