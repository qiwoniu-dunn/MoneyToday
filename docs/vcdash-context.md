## 一句话定位

MoneyToday 是一个住在 macOS 顶部菜单栏里的实时收入仪表，用户输入年薪和工作时间后，它会实时显示今天已经赚到的钱，并把金额换算成咖啡、午餐、相机、旅行等更有生活感的奖励。

## 核心目标

MoneyToday 的目标不是做财务管理，也不是制造绩效压力，而是给普通工作日增加即时反馈和情绪价值：

- 看见今天的劳动正在转化为具体收益。
- 用每 100ms 跳动的金额强化“正在发生”的感受。
- 用具体生活物品提供模糊的想象锚点和心理安慰。
- 避免显示“还差多少”，减少焦虑感。

## 技术结构

- `Sources/MoneyTodayApp/`：macOS 应用入口、菜单栏、popover、视图和图标。
- `Sources/MoneyTodayCore/`：收入计算、节假日服务、设置存储、奖励文案和物品池。
- `Sources/MoneyTodayChecks/`：轻量检查脚本，用于验证核心逻辑。
- `scripts/package_app.sh`：构建并打包 `.app`。
- `scripts/generate_app_icon.swift`：生成应用图标资源。
- `dist/`：本地发布产物。
- `docs/`：项目过程和管理文档。

## 关键设计决策

- 使用原生 macOS 菜单栏形态，减少存在感但保持随时可见。
- 菜单栏图标采用实心钱袋方向，避免早期线框图标不清晰的问题。
- 设置页默认收起到设置入口，主界面专注显示金额、进度和奖励。
- 节假日同步从主界面移除，只放到设置页手动触发，因为节假日数据是低频变化数据。
- 奖励系统只表达当前收入对应的生活想象，不显示距离下一个目标还差多少。
- 奖励物品基于日期稳定轮换，同一天保持稳定，跨天提供新鲜感。
- 1.2 奖励文案原则：奖励是模糊的生活想象锚点，不是精确兑换承诺；保留今日已赚金额，但不透出商品价格。
