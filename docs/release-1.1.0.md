# MoneyToday 1.1.0 发布记录

## 发布概览

- 版本号：1.1.0
- Git tag：`v1.1.0`
- 发布类型：情绪价值增强版
- 产品名：「窝囊费查看器 MoneyToday」
- 平台：macOS

## 主要新增

- 主界面支持 `日 / 周 / 月 / 年` 切换。
- 周/月/年显示截至当前时刻的已赚累计，不做兑换物折算。
- 日视图保留奖励兑换物，并优化为尽可能约等于一份兑换物。
- 奖励图从 SwiftUI 手绘升级为本地 PNG 资源，并新增 `RewardsV2/final-47` 清晰像素风商品图。
- 奖励候选池扩展为 5 个日薪层级、10 个阶段、每阶段 6 个具体品牌商品候选，共 300 个候选。
- 300 个具体商品候选收敛到 47 张通用商品图片，通过 `assetKey` 映射，避免后续图像资产失控。
- 日视图奖励区整合芝麻小猫轻动效和当前商品图片，形成陪伴式奖励呈现。
- 接入芝麻小猫 spritesheet，日视图奖励区展示轻动效。
- 增加主界面和设置页分区隐私眼睛按钮。
- 增加日期级周末自定义，周六周日可逐日标记工作或休息。
- 设置页增加兑换物对照表只读查看。
- 打包脚本生成 1.1.0 的 `.app`、`.zip`、`.pkg`。
- 修复 pkg payload 混入 `.DS_Store` 和 `._*` 隐藏文件的问题。

## 验证

- `swift build --disable-sandbox` 通过。
- `swift run --disable-sandbox MoneyTodayChecks` 通过。
- 检查覆盖周期累计、周末覆盖、奖励资产、芝麻 spritesheet 尺寸。
- 检查 `RewardsV2/final-47` 中 47 张清晰 PNG 资源可读取，且无 `.20x20.png` 模糊资产进入发布包。
- ZIP 解压检查通过。
- PKG payload 检查不包含 `.DS_Store` 或 `._*`。

## 已知限制

- 仍未做开发者签名和 Apple 公证。
- 奖励物价为内置近似锚点，不联网实时更新。
- 兑换物配置由项目维护者维护，App 内只读展示。
- 芝麻资源只做轻动效播放，不是完整宠物系统。
- 试用反馈显示当前奖励文案仍偏“价格换算/档位达成”，容易让用户较真商品价格。1.2 需要改成更模糊、更生活化的小确幸和心理安慰表达，不再在奖励文案中透出商品价格。
