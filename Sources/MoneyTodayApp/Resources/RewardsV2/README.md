# RewardsV2 Pixel Assets

This folder contains the reusable MoneyToday reward icon batch.

## Output Contract

- One PNG per generic asset key.
- File name format: `<asset-key>.png`, for example `reward-game-console.png`.
- Visual style: crisp pixel-art icon with visible blocky detail, generated and stored as a clear 512 x 512 PNG for app display.
- Brand names are not drawn into the image. The app text can say `PlayStation 5 Slim`, but the icon stays a generic slim game console and controller.

## Required Asset Count

The current reward-copy catalog has 300 concrete product options and maps to 47 reusable pixel assets.

MoneyToday 1.2 does not expand the product pool or product image categories. Add a new image only when a future product has a clearly different small-icon silhouette.
