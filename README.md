# 窝囊费查看器 MoneyToday

「窝囊费查看器 MoneyToday」是一个原生 macOS 菜单栏小工具。它会根据你的年薪、工作时间和工作日历，实时显示“今天已经赚到多少钱”，并把这串数字翻译成更有生活感的奖励，比如一杯咖啡、一顿午餐、一只鼠标、一台相机，或者一次小旅行。

它的目标不是制造焦虑，而是给每一天的劳动一点即时反馈：打开菜单栏，看见数字在跳，也看见今天的努力已经换成了什么真实的东西。

## 设计思路

MoneyToday 围绕三个原则设计：

- **轻量**：它只住在 macOS 顶部菜单栏，不占 Dock，不打扰工作。
- **可感知**：金额以 100ms 频率刷新，并显示 4 位小数，让“正在赚钱”这件事被看见。
- **有情绪价值**：除了金额，还会展示“已经赚到了什么”的生活物品换算。它只告诉你已经获得了什么，不显示“还差多少”，避免把奖励反馈变成压力。

## 1.0 功能

- 菜单栏实心钱袋图标。
- 点击图标打开悬浮面板。
- 首次启动进入设置页，填写年薪后开始计算。
- 支持设置年薪、货币、工作开始时间、工作结束时间。
- 默认工作时间为 `09:00` 到 `19:00`。
- 金额每 100ms 刷新一次。
- 今日已赚金额显示 4 位小数。
- 绿色直线进度条显示今日工作进度。
- 中国节假日和调休判断，支持本地缓存。
- 手动同步节假日数据。
- 测试模式：忽略周末和节假日，方便验收效果。
- 开机启动开关。
- 奖励文案和像素风物品图标。
- 年薪、设置和缓存都只保存在本机。

## 收入计算方式

MoneyToday 使用一个简单透明的模型：

```text
每日收入 = 年薪 / 当年工作日数量
每秒收入 = 每日收入 / 当天工作秒数
今日已赚 = 每秒收入 * 今天已经过去的工作秒数
```

如果当前不是工作日，金额不会增长；如果开启测试模式，则会忽略工作日判断，直接按设定工作时间运行。

## 情绪价值换算

MoneyToday 内置了一套面向中国大陆生活语境的人民币物价锚点表，并按日薪大致分为三档：

- 日薪 `< ¥500`：咖啡、奶茶、早餐、午餐、快餐、打车、电影等。
- 日薪 `¥500-¥1500`：餐厅、按摩、外设、香水、耳机等。
- 日薪 `> ¥1500`：运动相机、酒店、短途旅行、手机、电脑等。

换算结果会根据日期稳定轮换：同一天打开多次不会乱跳，第二天会有新的表达和新的奖励物品。

## 安装使用

从 Release 下载 `MoneyToday-v1.1.0.zip`，解压后打开 `MoneyToday.app`。

如果 macOS 提示来自未识别开发者，可以：

1. 右键点击 `MoneyToday.app`。
2. 选择“打开”。
3. 在系统提示里再次确认打开。

打开后，顶部菜单栏会出现 MoneyToday 钱袋图标。第一次点击图标会进入初始设置页，填写年薪并点击“保存并开始”即可。

## 从源码构建

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/module-cache" swift build --disable-sandbox
scripts/package_app.sh
open .build/app/MoneyToday.app
```

`CLANG_MODULE_CACHE_PATH` 会把 Swift/Clang 模块缓存放到项目内，避免受系统缓存目录权限影响。`--disable-sandbox` 是为了绕开某些受限命令行环境里 SwiftPM 的二层沙箱问题。

## 验证

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/module-cache" swift run --disable-sandbox MoneyTodayChecks
```

检查器会验证：

- 工作日前、中、后的收入计算。
- 节假日和调休逻辑。
- 测试模式。
- 节假日 API 数据解析。
- 奖励文案选择的稳定性和跨日变化。

## 隐私

- 年薪只保存在本机 `UserDefaults`。
- 节假日数据缓存在本机 Application Support 目录。
- MoneyToday 不上传你的年薪、设置或使用数据。
